# AC Advisory

Three site versions live on separate branches so you can flip between them.

**Retail prepared-foods (this branch)** — `cursor/retail-prepared-foods-cc13`  
Partnership layout and pages, with photography and copy focused on the retail set: shelves, grab-and-go sandwiches, salads, pinwheels, wraps, snacking trays, ready meals, pizza, sushi trays and soup cups.

**Partnership pages** — `cursor/partnership-pages-cc13`  
Tabs: Home, Manufacturers, Retailers, Our Expertise, Why Us, About, Contact, plus Let’s Talk.

**Prestige one-pager (backup)** — `cursor/prestige-advisory-site-cc13`

```bash
npm install

```
